# WealthPilot AI — 合规与适当性设计（v0.5）

> **声明**：本项目是作品集演示系统，不销售产品、不接触真实资金。本文的规则是对国内理财销售实践的**演示性建模**，不构成法律意见，也不等同于任何机构的完整监管实施。标记 ⚠️ 的条目需持牌机构或合规人员确认。

---

## 1. 核心原则：先测评，后服务

产品负责人决定（2026-10-16）：**国内理财产品销售须先完成风险承受能力评估，因此 Agent 在会话开始时就核对客户测评状态。测评前只回答范围受限的金融常识，并持续提醒先做测评；推荐产品必须在测评完成之后。**

落地方式（详见 ARCHITECTURE §4.2–4.3）：

| 状态 | Agent 能做 | Agent 不能做 |
|---|---|---|
| 未测评 / 测评过期 | 回答金融常识（附测评提醒）；通用复利/通胀计算；弹出测评问卷；客户要求时发起人工交接 | 查询任何产品信息；推荐、筛选、比较产品；讨论配置 |
| 测评有效（C1–C5） | 在评级允许范围内查询、比较、计算、模拟配置 | 推荐或排序超出评级的产品；承诺收益 |
| 任何状态 | — | 回答与理财无关的问题（天文地理、写代码等），统一固定话术，不调用主模型 |

这条规则在**三个层面**生效，而不仅写在 Prompt 里：

1. **流程层**：`policy_gate` 节点根据数据库中的测评记录计算权限，未测评时 LLM 只绑定两个工具。
2. **工具层**：产品类工具内部再校验一次评级（防止绕过流程直接调用 API）。
3. **输出层**：`output_guard` 检查未测评状态下回答中不出现产品名称和收益数字。

## 2. 模拟风险测评

- 问卷约 10 题：年龄段、收入稳定性、可投资资产占比、投资经验、投资期限、最大可承受亏损、投资目标、金融知识。明确标注「**模拟问卷，非任何机构正式问卷**」。
- 计分规则确定、版本化（`questionnaire_version`），结果映射为 C1（保守）至 C5（激进）。
- **一票否决题**：例如「不能接受任何本金损失」→ 无论总分多少均评为 C1。
- 评级只能由问卷计分产生，**聊天中自称「我是激进型」不改变评级**。
- 每次测评新增记录，不覆盖历史。
- 完整题目、分值、分档与校准验证见 [RISK_QUESTIONNAIRE.md](RISK_QUESTIONNAIRE.md)。

| 参数 | 演示取值 | 说明 |
|---|---|---|
| 测评有效期 | 12 个月 | 参考中国银行《代销理财产品投资者权益须知（2022 年版）》；可配置 |
| 客户确认 | 系统计分后展示评级，客户确认后才生效 | 参考同上 |
| 重测频率限制 | 距上次确认评级 24 小时内不能再测评 | ⚠️ 防止客户反复重测「刷」高评级；具体限制以机构制度为准 |
| 风险匹配 | 产品风险等级 ≤ 客户评级（C1↔PR1 … C5↔PR5） | 演示采用最常见的五级对应 |

## 3. 规则清单（Policy Engine）

规则是纯函数：`evaluate(context) -> PolicyDecision`，每次决策记录 `rule_version` 与输入快照。

| 代码 | 触发条件 | 动作 | 层级 |
|---|---|---|---|
| `ASSESSMENT_MISSING` | 无测评记录 | 限制工具 → 引导测评 | 门禁 |
| `ASSESSMENT_EXPIRED` | 超过有效期 | 同上，提示重新测评 | 门禁 |
| `REASSESSMENT_RATE_LIMITED` | 重测过于频繁 | 拒绝本次提交，说明原因 | API |
| `PRODUCT_RISK_EXCEEDS_RATING` | 产品等级 > 客户评级 | **硬过滤**：不进入候选、不参与排序；客户点名查询时仅展示条款 + 风险提示 | 工具 |
| `OUT_OF_SCOPE` | 与理财无关的问题 | 固定话术，不调用主模型 | 路由 |
| `PRODUCT_NOT_ON_SALE` | 产品非在售状态 | 可作为资料讲解，不进入候选 | 工具 |
| `BELOW_MINIMUM_INVESTMENT` | 金额低于起购额 | 不进入候选，说明原因 | 工具 |
| `HORIZON_MISMATCH` | 封闭期 > 客户投资期限 | 不进入候选 | 工具 |
| `LIQUIDITY_RESERVE_CONFLICT` | 配置会占用客户声明的流动性储备 | 情景中标红并说明 | 工具 |
| `UNVERIFIED_PRODUCT_DATA` | 关键字段未核实 | 可展示（带警示），不参与排序 | 工具 |
| `GUARANTEE_REQUESTED` | 客户要求保本保收益 | 解释资管新规后打破刚兑，不作承诺 | 输出 |
| `RATING_OVERRIDE_ATTEMPT` | 聊天中要求「按 C5 给我推荐」 | 拒绝；说明只能重新测评 | 门禁 |

### 3.1 关于数据来源与「在售」

- **全部为虚构产品**（产品负责人决定，2026-10-17）：机构与产品均为虚构（`SYNTHETIC`），界面明确标注「虚构演示产品」。产品中不出现任何真实银行或理财公司的产品信息。
- 真实公开说明书只作为本地设计参考（结构、要素、常见条款写法），不进入产品库和 RAG，不摘录原文。详见 [PRODUCT_CATALOG.md](PRODUCT_CATALOG.md)。


**产品评级不一致时取较高者**：同一产品若有多个风险评级（如发行机构评级与代销机构评级不同），采用较高的评级参与适当性匹配（参考中国银行代销规则）。Phase 3 产品库实现。

### 3.2 已确认的边界（产品负责人，2026-10-16）

- **客户主动点名询问超出其评级的产品**：可以展示该产品的客观条款，同时给出风险提示，不做推荐。产品卡片显著标注「该产品风险等级超出您的风险承受能力，不作推荐，您亦无权限购买」，且不进入候选和排序。
- **测评前的金融常识**：可以回答，但限于理财与金融范围（`scope_router` 控制），每条回答附测评提醒和入口；客户要求推荐产品时，必须先完成测评。

### 3.4 客户等级权益与新品预约（产品负责人，2026-10-18）

- **等级权益与资产总额挂钩**：按月日均金融资产（存款、理财等均计入）评定，不与购买某款理财产品挂钩；礼遇以服务和积分形式提供，积分不可兑现金；等级以银行评定为准，AI 不承诺一定能升级。
- **主动提示**：计划资金转入后可达下一等级时，由代码在回答末尾追加一次固定措辞的提示（含「新转入资金」前提与「以银行评定为准」）；模型只在客户主动问起时谈等级。
- **新品预约**：可如实介绍募集期、募集规模上限（额满提前结束募集）和业绩比较基准；不说「高收益」「很多人抢」「赶紧」；只推荐、只允许预约评级范围内的新品；客户本人点击或在对话中明确同意后才设置提醒；提醒不等于购买，不锁定额度，开售后由客户本人确认买入。

### 3.3 销售与买入（产品负责人，2026-10-18）

- **产品可见性**：全部在售产品都可在「理财产品」页浏览（含未测评客户），超出评级的标注「仅可查看」。AI 对话中仍只在评级范围内推荐；未测评时 AI 仍不讨论具体产品。
- **需求匹配式推荐**：测评后 AI 可以推荐 1–3 款评级范围内的产品，理由只能是期限、流动性、费用、起购金额与需求的匹配。
- **买入只做到确认页**（演示，不下单）。服务端校验：有效测评、产品风险 ≤ 客户评级、在售、申购费率已核实、金额 ≥ 起购金额、金额 ≤ 可用活期余额；客户必须勾选已阅读《产品说明书》《风险揭示书》《理财产品销售协议书》。AI 不能代客户下单。
- **联系理财经理**：客户界面只展示理财经理名片（企业微信、电话），并告知「咨询要点已同步」；不展示客户资料确认卡片。摘要只同步给客户的专属理财经理（行内流转）。

| `O-UNGROUNDED_PRODUCT` | 提到的产品不在本会话工具结果中 | 同上 |
| `O-PERMISSION_LEAK` | 未测评状态下出现产品名称或推荐类表述（客户自己说过的产品、银行系统中客户已有的持仓除外） | 带反馈改写；仍失败则兜底 |

| `O-FALSE_ACTION_CLAIM` | 宣称完成了并未发生的操作：「已为您预约开售提醒」但本轮工具结果与客户资料中都没有提醒记录；「已为您买入 / 锁定额度」（AI 无法代客户买入，一律拦截） | 带反馈改写；仍失败则兜底（P8-2b 场景评估 N02 发现模型没调用工具就说已预约） |
| `O-GIFT_FOR_PURCHASE` | 把礼品、积分、返现与购买某款产品挂钩（「购买 X 即送 2000 积分」） | 带反馈改写；仍失败则兜底（§3.4） |
| `O-UNGROUNDED_FIGURE` | 紧跟在「业绩比较基准 / 七日年化 / 万份收益」之后的百分数（含区间），没有出现在本轮工具结果或此前对话中（数值相同即可，如 2.8% 与 2.80%） | 带反馈改写；仍失败则兜底（场景评估发现模型编造新品的业绩比较基准） |
| `O-UNGROUNDED_AMOUNT` | 回答中的人民币金额（元 / 万元 / 亿元 / ¥ / million）没有出现在工具结果、客户资料、客户自己说的话或知识库中；允许 0.1% 的四舍五入差异（162.89 万 ≈ 1,628,894.63；曾用 0.5%，漏拦了把 99,500 写成 995,000 的错误）。**举例的假设金额可以使用**（产品负责人决定，2026-10-19）：同一句中写明「假设 / 例如 / 比如 / 举例」（英文 suppose / assume / for example / e.g. 等），且是有效数字不超过 2 位的整数金额（60 万元、¥1,500,000）；同一金额在后文再次出现时沿用该假设。由假设金额算出的结果（10.3 万元、¥1,790,848）不是整数金额，仍须来自计算工具 | 带反馈改写（先调用计算工具；工具算不了的差额改用文字描述；举例只写假设的整数金额）；仍失败则兜底（P8-4，2b 评估中模型自己算错到手金额） |
| `O-FALSE_HANDOFF_CLAIM` | 「已为您接通 / 已联系理财经理 / 理财经理已接入」等表述（AI 无法得知理财经理是否已联系客户） | 带反馈改写为「已将咨询要点同步给理财经理，您可以通过名片直接联系」 |
| `O-DISCLAIMER` | 涉及产品或收益数字 | 由代码追加标准风险提示（不依赖 LLM） |
| `O-NO_GUARANTEE` | 客户问题含「保本 / 保收益 / 稳赚 / 零风险」，而回答没有明确否定（「不保本 / 不承诺收益」） | 由代码追加「银行理财产品不保本、不承诺收益，包括低风险的现金管理类产品」（P7 场景评估发现模型会回避正面回答） |

输出审查的判定细则（P7 场景评估中校准）：
- **否定按分句判断**：关键词前 20 字内、同一分句中有「不 / 无法 / 不能 / 并非…」才算否定；「不仅 / 不但 / 毫不」不算否定。
- **引用的警示语不算承诺**：引号内的短语（如「保本保收益」），同一句中有「虚假 / 不要 / 警惕 / 所谓…」等警示语境时豁免。
- **诱导调高评级的两种形式**：①「重新测评 / 调高评级」与「收益 / 更高风险 / PR3+」同句；②「提高风险等级」与「建议 / 可以 / 考虑 / 如需」同句。同句说明限制（超出 / 不匹配 / 无权购买）属于如实告知，不拦截，如「更高的收益通常意味着更高的风险，这超出了您当前的风险等级」。
- **诱导按段落判断**：同一段落中「重新测评」与「收益 / 更高风险 / PR3+」同时出现即视为诱导（两句分开写，连起来读仍是「想要 5% 就去重新测评」）。讨论收益或更高风险时，AI 不主动提重新测评；入口在界面「风险测评」栏。
- **代码补充的说明**：客户问到保本时补充「理财不保本」；客户自称年龄与银行登记不一致且回答未说明时，补充「以银行登记为准」；配置模拟的目标收益检查中写明「目标不是承诺」。
- **改写反馈要具体**：给模型的改写反馈引用违规句原文。P7 发现诱导类违规的反馈中没有原句，模型改写后重复同一表述、最终兜底。
- **被拒绝的初稿不能作为依据**（2026-10-19）：核对产品、收益数字、金额是否「有来源」时，依据只包括客户的话、工具结果、客户资料、知识库和以往轮次的最终回答，不包括本轮模型自己写的内容。修复前，被拒绝的初稿算作「此前的消息」，改写时重复同一个编造的金额或产品就能通过：评估 R01 中模型自算的「超出 11.2 万元」、C01 中自算的 6% 复利结果都曾因此通过。修复后这些情况改写不成功就兜底（`test_rejected_draft_cannot_ground_*`）。
- **改写反馈要说明怎么改**：只说「金额没有来源」「引用了未检索的编号」时，模型常常原样重写。反馈现在给出具体做法：先调用计算工具；工具算不了的差额改用文字描述（「超出 50 万元的部分」）；引用上一轮的资料要在本轮重新检索。
- **删句优先于兜底**：诱导重新测评的句子是附加建议，删去不影响回答主体；只在这一种违规单独出现时使用（决策记录为 `REDACT`）。其他违规（承诺收益、泄露产品等）往往是回答主体，仍走兜底。
- **审计可追溯**：改写、删句或兜底时，决策记录同时保存原因代码与违规片段。

### 4.1 英文界面（P8-2b，2026-10-18）

英文版是同一个中国市场产品的完整英文界面（给美国面试官看），合规要求与中文完全相同：
- **每条输出规则都有英文版**（`output_guard.py` 中的 `*_EN`）：如 guaranteed returns / principal-protected / risk-free / can't lose；limited-time / act now / don't miss out；retake the profile / raise your risk rating；benchmark 与 7-day yield 的比较；I've connected you / your RM is now online；真实理财公司的英文名称（如 CMB Wealth）。
- **中文界面只用中文规则，行为与之前完全一致**；英文界面中英文规则同时生效——模型在英文回答里夹带中文表述（如「稳赚」）同样会被拦截。
- **英文否定判断**：关键词前 45 个字符内、同一分句中有 not / no / never / cannot / n't / without 等即视为否定（英文否定词与被否定词通常相隔更远）；not only / no matter 不算否定。引号内的短语在 misleading / beware / so-called 等警示语境中豁免。
- **英文分句**：句末标点后须有空白才断句，避免把小数点（2.5%）当作句末；段落级诱导检查同样适用。
- 「complete your risk profile」是给未测评客户的正常提示，不算诱导；只有 retake / redo / reassess 与收益、更高风险同句或同段才拦截。
- **代码追加的说明全部双语**：理财不保本、假设情景、年龄以银行登记为准（识别 "I'm 35" 等英文自述）、等级升级提示。
- **资料原文不翻译**：知识库与产品说明书是中文原文，英文界面只翻译出处标题，摘录保持中文并标注 "Source text in Chinese"，避免机器译文被当作法规原文引用；检索仍用中文查询。
- 场景评估中校准的英文细则：否定窗口从 45 扩到 100 字符（"regulations do not allow me to sell you a product with a guaranteed return"）；"non-principal-protected" 视为否定；转述他人说法（any product claiming… / if anyone tells you…）与否定同样处理；同句有 misleading / non-compliant / illegal 等定性词时，无引号也视为警示语境；"no risk" 只在 "there's / it carries no risk" 等断言中拦截。
- 用例：`backend/tests/test_compliance_en.py`（每条规则的违规句与合规否定句）；英文场景评估 `evaluations/scenarios_en.yaml`（与中文 25 个场景一一对应）。

收益表述约定：
- 「业绩比较基准」≠ 预期收益 ≠ 保证收益；任何计算情景都标注「假设情景，非预测，非承诺」。
- 历史收益必须带区间（起止日期）和口径。

## 5. 人工交接触发

| 类型 | 触发原因（PRD 枚举） | 动作 |
|---|---|---|
| 客户请求 | `USER_REQUEST` | 立即展示理财经理名片，同步咨询要点 |
| 强制人工 | `REGULATED_ADVISORY_REQUEST`（要求完整投资方案、交易）、`HUMAN_AUTHORIZATION_REQUIRED` | 说明 AI 能力边界 → 建议交接 |
| 建议人工 | `HIGH_COMPLEXITY`（退休+税务+房产）、`LOW_RETRIEVAL_CONFIDENCE`、`UNVERIFIED_PRODUCT_DATA`、`TOOL_FAILURE`、`MISSING_CRITICAL_INFORMATION` | 提供教育性信息 + 询问是否转人工 |
| 冲突 | `SUITABILITY_CONFLICT` | 解释冲突；**转人工不会解除适当性限制**，交接摘要中写明冲突 |

硬性要求：
- 客户界面只展示理财经理名片与「咨询要点已同步」提示，不展示客户资料（产品负责人决定，2026-10-18）。
- AI 只能说「已将咨询要点同步给理财经理，您可以通过名片直接联系」，不能说理财经理已联系客户、已接入或正在服务。
- 演示数据不含真实联系方式：点击企业微信 / 电话时提示「演示环境」，不会联系真实银行工作人员。

## 6. 隐私与安全

- 全部使用虚构演示客户；不收集真实身份信息。
- API Key 只在 `.env`，不入库。
- 日志只记录工具名、状态、耗时和摘要，不记录完整对话内容（对话存业务表，受角色权限保护）。
- 理财经理只能查看已同意交接的会话。
- 文档内容视为不可信输入，防止提示注入（评估集含专门用例）。

### 6.1 语音输入（2026-10-18）

- 录音在本机识别（本地开源模型），不发送给第三方；音频只在内存中处理，识别后即丢弃，不写日志、不落盘。
- 识别结果先填入输入框，由客户确认或修改后发送，金额等关键数字可在发送前核对。
- 语音只是输入方式：买入、预约提醒等操作仍需客户在屏幕上点击确认；风险揭示以文字为准，朗读只读结论并提示「详细内容请看屏幕」。
- 录音时界面提示「录音只在本机转成文字，不保存」。
